# vmixcenter OpenLP stage

`stage.html`, `stage.css`, and `stage.js` are the source files for the centered
lyric stage at `openlp/data/stages/vmixcenter`. Copy these three files to that
folder when updating the stage. The deployed folder keeps its local
`jquery.min.js`, `NotoSansSC-VariableFont_wght.ttf`, and favicon assets.
